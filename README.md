# 🍵 Sonsuz Çay Demleme Dengesi

## Bu Ne?

Bu repository, insanlığın en büyük sorunlarından birini çözmeyi hedeflemektedir: **Çayın demlenme dengesini sonsuza kadar korumak.**

Bilimsel araştırmalar (hiçbiri yok) göstermiştir ki çay demleme işlemi, evrenin entropisiyle doğrudan ilişkilidir. Bu kod, o ilişkiyi görmezden gelerek sonsuz bir döngüde çay demliyor gibi yapar.

### Özellikler

- ✅ Gerçekten çalışır (sonsuz döngü şeklinde)
- ✅ Sıcaklık takibi yapar (rastgele)
- ✅ Denge bozulursa kendini resetler
- ✅ Ctrl+C ile durdurulabilir (tavsiye edilir)
- ❌ Gerçek çay üretmez
- ❌ Mantıklı değildir
- ❌ Faydalı değildir

### Kullanım

```bash
python demle.py
```

Durdurmak için `Ctrl+C` basın. Çay demlenmeyecek, ama en azından denedin.
